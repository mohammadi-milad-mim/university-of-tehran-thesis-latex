پوستر از اطلاعات و چکیده پایان‌نامه استفاده می‌کند. زمان و مکان را در `details.tex` وارد کنید. از پوشه `thesis-latex` دستور `make poster` را اجرا کنید.

The poster shares thesis metadata, abstract, logos, and fonts. Edit `details.tex` for defense logistics. Run `make -C thesis-latex poster` from the repository root. Output: `defense-poster-template/output/defense-announcement.pdf`.
