# نمونه خروجی / Sample output

این فایل‌ها فقط از متن‌ها و داده‌های نمونهٔ همین مخزن ساخته شده‌اند و همراه قالب در گیت نگهداری می‌شوند.

These curated thesis and defense-poster PDFs are versioned examples. Normal builds write to the ignored `thesis-latex/output/` and `defense-poster-template/output/` directories; they never overwrite these samples. To refresh a sample intentionally, verify the generated PDF first, then copy it here.
