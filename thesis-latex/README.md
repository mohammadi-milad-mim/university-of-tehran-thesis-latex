# قالب لاتک پایان‌نامه

از `metadata.tex` برای مشخصات، `chapters` برای فصل‌ها، `appendices` برای پیوست‌ها، `bibliography/references.bib` برای منابع و `glossary/terms.tex` برای اصطلاح‌ها استفاده کنید. ترتیب فصل‌ها در `main.tex` است. شکل‌ها و داده‌ها در پوشه‌های مشترک هم‌سطح قرار دارند.

```sh
make doctor
make pdf
make verify
make poster
```

همه مثال‌ها ساختگی و آموزشی هستند. حاشیه‌ها ۲۵ میلی‌متر و فونت‌ها IRNazanin و TeX Gyre Termes هستند. برای راهنمای کامل به README ریشه مراجعه کنید.
